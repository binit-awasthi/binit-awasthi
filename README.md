## Featured Projects

### 🖊️ [HMER — Handwritten Math Expression Recognition](https://github.com/binit-awasthi/hmer)

A deep learning system that converts images of handwritten mathematical expressions into LaTeX strings.

**Architecture:** ResNet-34 backbone (truncated at `layer3`, stride 16) → 128 spatial tokens → Transformer Encoder (2L, 8H) → Transformer Decoder (4L, 8H) → LaTeX sequence

| Metric | Score |
|--------|-------|
| Token Accuracy | 94.43% |
| Expression Recognition Rate (ExpRate) | 44.52% |

Trained on the [MathWriting](https://huggingface.co/datasets/deepcopy/MathWriting-human) dataset (~230k samples).

> 🤗 **[Try the live demo on Hugging Face Spaces](https://huggingface.co/spaces/binit-awasthi/hmer-demo)**
