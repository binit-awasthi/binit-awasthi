#### 🖊️ [HMER — Handwritten Math → LaTeX](https://github.com/binit-awasthi/hmer)

Converts images of handwritten mathematical expressions into LaTeX strings using a ResNet-Transformer architecture trained on ~230k samples.

**Architecture**
```
Image (128×256)
  → ResNet-34  (stride 16, 128 tokens)
  → Transformer Encoder  (2L · 8H)
  → Transformer Decoder  (4L · 8H)
  → LaTeX sequence
```

| Metric | Score |
|--------|-------|
| Token Accuracy | **94.43%** |
| ExpRate (exact match) | **44.52%** |

> 🤗 [**Try the live demo**](https://huggingface.co/spaces/binit-awasthi/hmer-demo)
